AbdQuest — Privacy Policy

Last updated: June 2026

AbdQuest is a personal habit- and fitness-tracking web application created and used by a single individual. It is not a commercial product and is not offered as a service to the public.

What data the app handles

All data entered into AbdQuest (habits, prayers, workouts, weight, calories, notes, and similar personal records) is stored locally in the browser storage of the user's own device. The app has no backend server and no database. No data is transmitted to, collected by, or stored by the app's author or any third party.

Google Health API

With the user's explicit consent via Google's OAuth screen, AbdQuest can read the user's own fitness data (such as steps, sleep, heart rate, calories, and nutrition) from the Google Health API. This data is fetched directly from Google to the user's device, is displayed and stored only on that device, and is never sent anywhere else, shared with anyone, sold, or used for advertising. Access can be revoked at any time at myaccount.google.com/permissions, and the in-app "Disconnect" button deletes the stored access credentials from the device.

Limited Use disclosure

AbdQuest's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used solely to display the user's own fitness information to that user within the app.

Cookies and analytics

AbdQuest uses no cookies, no analytics, no trackers, and no advertising.

Terms of use
